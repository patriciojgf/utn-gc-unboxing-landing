# Unboxing — Landing page

Landing de Unboxing, el marketplace de packaging personalizado (TP de Gestión Comercial, UTN FRBA, 2026).

Es un sitio estático: `index.html` y la carpeta `assets/`. No necesita compilar nada.

## Publicarla con GitHub Pages

1. Crear un repositorio nuevo en GitHub (por ejemplo `unboxing-landing`) y subir todo el contenido de esta carpeta a la raíz.
2. En el repositorio: **Settings → Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guardar.
4. En uno o dos minutos queda publicada en `https://<usuario>.github.io/unboxing-landing/`.

## Verla en la compu

Abrir `index.html` con doble clic.
